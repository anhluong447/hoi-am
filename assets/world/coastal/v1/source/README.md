# Coastal world art v1

Original rasters generated with built-in imagegen. Exact submitted prompts are
in `prompts.json`; source PNGs are preserved byte-for-byte, and runtime PNGs are
copies of those sources. No character, UI, or reference pixels were edited.

Actual generated dimensions differ from requested dimensions. Manifest v1 records
automatic alpha bounds of the initial prop-grid experiment. Manifest v2 uses
reviewed prop regions to exclude neighboring-cell fragments and adds surface and
harbor atlases. Regions are metadata: no cropped/resized output replaces a source.

The sheet is original generated art, not hand-layered artist source. Runtime
assembly supplies separate depth layers, pivots, collisions and shadow proxies.
All paper/sign regions are blank; readable world text must come from the catalog.
Selected style is painted raster clusters, compared against 3-texel quantization
in HD03 evidence. Final user visual acceptance remains pending.
