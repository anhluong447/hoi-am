# Coastal companion and outdoor art

Original assets generated with built-in imagegen. Exact prompts are in
`prompts.json`; the original output files remain in Codex's generated_images folder.
Source and runtime PNGs are byte-identical; manifest v3 records hashes/dimensions.
No raster resizing, alpha editing or synthesized text was applied.

Companion actual dimensions: 1086x1448 (requested 1536x2048, 3x4 cells).
Outdoor actual dimensions: 1254x1254. The requested strict 3x3 grid was not followed
exactly: the tree/palm and pier vary in width. Regions are manually authored
metadata around full isolated silhouettes, rather than truncating to grid cells.
Native captures review those selections; source pixels remain unchanged.

Companion supplies cafe seating, bed, chalkboard, arch, awning, jars, printing press,
laptop, pendant light, painting and bench. Outdoor supplies broad tree, palm, shrub,
school facade, warehouse, stone railing, pier, streetlamp and blank notice stand.
These are generated pilot art masters, not layered hand-authored production files.
Readable signs are live Label3D catalog text, never baked into these PNGs.
