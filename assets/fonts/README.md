# Font provenance

Source Serif 4 được nhập từ font pack coastal của hai-vong, giữ nguyên TTF,
OFL và METADATA trong source_serif_4/. Hash nằm trong
[import inventory](../../docs/reference/import-inventory.json).

Theme bootstrap dùng font này để hiển thị tiếng Việt. Đây chưa phải nghiệm thu
typography bốn màn UI; Chapter 5 sẽ kiểm tra font role/size/weight/metrics và nhập
các family còn cần thiết. Giữ license và thêm version mới nếu thay font source.
