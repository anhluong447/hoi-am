# HD-2D world development

The approved [roadmap](../plans/hd2d-world-roadmap.md) is implemented on branch
`feature/hd2d-world`, with one chapter per commit. The user authorized completing
all chapters without waiting at intermediate visual checkpoints. Technical
verification and agent visual review do not imply final user art acceptance.

Reference composition: warm newsroom wood/paper, cool teal ink and harbor,
layered foreground foliage, readable pixel characters, window sunlight.

Composition layers: floor/room shell, furniture and interactive objects, actors,
foreground cutouts, then harbor/sky at distinct background depths. Existing UI
is separate and retains its accepted layout and dialogue motion.

See [asset inventory](asset-inventory.json), [chapter status](status.json), and
[ADR 004](../decisions/004-hd2d-world.md).

All eight locations select painted HD-2D packs. See [room compositions](room-compositions.md),
[authoring](authoring.md) and [final review](hd09-review.md). Final captures are in
evidence/hd09-locations-v4; the 46-second tour is in evidence/hd09-tour-v1.
Earlier captures remain as iteration evidence, not competing selected variants.
